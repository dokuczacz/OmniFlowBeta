# Copilot Global Skills Pack

This folder contains a ready-to-import global package for user-level Copilot customization.

## Included skills
- omniflow-stall-escalation
- omniflow-progress-table-strict
- omniflow-operator-commands
- omniflow-test-operator
- omniflow-self-learner-mini

## Suggested install (manual copy)
1. Copy each skill folder from `tmp/copilot-global-pack/skills/` to your user-level skills location.
2. Keep repo-only domain skills in `.github/skills/` inside this repository.
3. Validate trigger behavior with quick smoke prompts.

## Scope policy
- Global skills: cross-project behavior and operational discipline.
- Repo skills: domain architecture, orchestration contracts, and project runbooks.
